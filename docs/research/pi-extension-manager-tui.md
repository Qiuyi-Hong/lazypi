# Extension-manager TUI: published reference evidence

Scope: inspected the **published** [`@vanillagreen/pi-extension-manager@3.0.1` manifest](https://registry.npmjs.org/%40vanillagreen%2Fpi-extension-manager/3.0.1) and [npm tarball](https://registry.npmjs.org/@vanillagreen/pi-extension-manager/-/pi-extension-manager-3.0.1.tgz), without installing or running it. Tarball SHA-512 matched the manifest integrity; cited GitHub files at [commit `8222af2`](https://github.com/vanillagreencom/kendex/tree/8222af276277d3461b8a7ebf0c9ffdd1c9a0384f/pi-extensions/pi-extension-manager) have matching Git blob hashes. This describes the **package browser**, not the separate settings editor shown in the [bundled GIF](https://github.com/vanillagreencom/kendex/blob/8222af276277d3461b8a7ebf0c9ffdd1c9a0384f/pi-extensions/pi-extension-manager/assets/extension-manager.gif) ([editor uses tabs](https://github.com/vanillagreencom/kendex/blob/8222af276277d3461b8a7ebf0c9ffdd1c9a0384f/pi-extensions/pi-extension-manager/extensions/manager/quick-settings-ui.ts#L335)).

## Observable composition and priority

- Centered framed overlay titled **Extension Manager**, width `92%`, height capped at `85%`; top search field, explicit state/scope filter strip, contextual action hints, divider, then a two-column **Packages (count)** list and persistent selected-item inspector; a small paging/diagnostics footer follows. The browser has **no top tab bar** (that belongs to settings). [Browser renderer](https://github.com/vanillagreencom/kendex/blob/8222af276277d3461b8a7ebf0c9ffdd1c9a0384f/pi-extensions/pi-extension-manager/extensions/manager/manager-ui.ts#L204-L237), [overlay/footer](https://github.com/vanillagreencom/kendex/blob/8222af276277d3461b8a7ebf0c9ffdd1c9a0384f/pi-extensions/pi-extension-manager/extensions/manager/manager-ui.ts#L378-L407).
- Compact **one-line list rows**: state dot (green active, yellow other, red broken), name, subdued scope/kind, red update badge; a full-row background marks selection. Inspector starts with bold accented name, state/update, description, then labeled scope/source/state reason/version/update; conditional action, trigger, shadow/error, and up to five extension names follow. Distinct muted section labels and subdued metadata keep identity/status foremost. [List](https://github.com/vanillagreencom/kendex/blob/8222af276277d3461b8a7ebf0c9ffdd1c9a0384f/pi-extensions/pi-extension-manager/extensions/manager/manager-ui.ts#L118-L201), [styling](https://github.com/vanillagreencom/kendex/blob/8222af276277d3461b8a7ebf0c9ffdd1c9a0384f/pi-extensions/pi-extension-manager/extensions/manager/render.ts#L74-L94).
- Density is bounded: at most **18 list items** per viewport plus earlier/more counts; diagnostics swap in as a separately scrolling screen with inventory counts and manifest/file summaries, not permanent chrome. [Viewport/list](https://github.com/vanillagreencom/kendex/blob/8222af276277d3461b8a7ebf0c9ffdd1c9a0384f/pi-extensions/pi-extension-manager/extensions/manager/manager-ui.ts#L52-L102), [diagnostics](https://github.com/vanillagreencom/kendex/blob/8222af276277d3461b8a7ebf0c9ffdd1c9a0384f/pi-extensions/pi-extension-manager/extensions/manager/manager-ui.ts#L70-L108), [limits](https://github.com/vanillagreencom/kendex/blob/8222af276277d3461b8a7ebf0c9ffdd1c9a0384f/pi-extensions/pi-extension-manager/extensions/manager/types.ts#L4-L18).
- **Narrow-width caveat:** list width scales from about 45% toward 38% (capped at 48 columns), inspector has a 20-column floor, and separator costs three; below **41 content columns**, the columns exceed available width and the frame truncates the combined line. List names truncate; filter/inspector text wraps, but inspector is top-sliced vertically. There is **no stacked narrow-screen fallback** in this renderer. Height shrinks to a minimum 14 inner rows. [Columns](https://github.com/vanillagreencom/kendex/blob/8222af276277d3461b8a7ebf0c9ffdd1c9a0384f/pi-extensions/pi-extension-manager/extensions/manager/manager-ui.ts#L134-L160), [composition](https://github.com/vanillagreencom/kendex/blob/8222af276277d3461b8a7ebf0c9ffdd1c9a0384f/pi-extensions/pi-extension-manager/extensions/manager/manager-ui.ts#L175-L239), [frame truncation](https://github.com/vanillagreencom/kendex/blob/8222af276277d3461b8a7ebf0c9ffdd1c9a0384f/pi-extensions/pi-extension-manager/extensions/manager/render.ts#L42-L66), [height](https://github.com/vanillagreencom/kendex/blob/8222af276277d3461b8a7ebf0c9ffdd1c9a0384f/pi-extensions/pi-extension-manager/extensions/manager/settings.ts#L238-L252).

## Contrast / reusable pattern, not a decision

LazyPi currently places **eight section tabs across two truncated lines** above search; list rows use name/state plus a muted description line (Extras may add metadata), max seven visible items; Enter **replaces** the list with details rather than maintaining a side inspector. Its centered overlay requests width 78/max height 26 and rendering caps at 76, truncating text rather than wrapping it. [LazyPi UI](https://github.com/Qiuyi-Hong/lazypi/blob/1be61e95610ecf671a2779ca0c0d8bd90d514b1c/src/ui.ts#L20-L36), [render](https://github.com/Qiuyi-Hong/lazypi/blob/1be61e95610ecf671a2779ca0c0d8bd90d514b1c/src/ui.ts#L298-L465), [overlay](https://github.com/Qiuyi-Hong/lazypi/blob/1be61e95610ecf671a2779ca0c0d8bd90d514b1c/extensions/lazypi.ts#L337-L437). **For comparison only:** list/detail adjacency, stronger selected-row/status contrast, quieter metadata and bounded diagnostics are reusable visual patterns; reference width behavior is not a proven narrow-layout solution. [Reference renderer](https://github.com/vanillagreencom/kendex/blob/8222af276277d3461b8a7ebf0c9ffdd1c9a0384f/pi-extensions/pi-extension-manager/extensions/manager/manager-ui.ts#L118-L239).

**Do not transfer labels as semantics.** The reference browser lists package summaries, using their *extension modules* in search and inspector; its `active/disabled/shadowed/broken` inventory and `extensions: []` disabled test describe extension-manager state, not LazyPi's all-resource package state. [Filter](https://github.com/vanillagreencom/kendex/blob/8222af276277d3461b8a7ebf0c9ffdd1c9a0384f/pi-extensions/pi-extension-manager/extensions/manager/filters.ts#L13-L56), [reference disabled test](https://github.com/vanillagreencom/kendex/blob/8222af276277d3461b8a7ebf0c9ffdd1c9a0384f/pi-extensions/pi-extension-manager/extensions/manager/inventory.ts#L70-L80), [reference inventory](https://github.com/vanillagreencom/kendex/blob/8222af276277d3461b8a7ebf0c9ffdd1c9a0384f/pi-extensions/pi-extension-manager/extensions/manager/inventory.ts#L310-L357). LazyPi's Pi-native packages can contain **extensions, skills, prompts, themes**; package disable applies all four empty filters, while partial filters are **custom**, missing paths **missing**, and user entries can be **shadowed**. Core, Extras and Community are separate LazyPi categories, not extension modules. Keep Pi settings/native package manager authoritative. [Architecture](https://github.com/Qiuyi-Hong/lazypi/blob/1be61e95610ecf671a2779ca0c0d8bd90d514b1c/docs/architecture.md#L7-L21).

Open for the layout comparison, not decided here: whether a persistent inspector can fit dense Extra-selection and truthful package-status text at typical/narrow terminal widths; static published source shows the reference's truncation but not actual terminal behavior under those conditions.
