# LazyPi

LazyPi is an enhancement layer for vanilla Pi that organizes independently manageable Pi packages.

## Language

**Package**:
An installable unit managed by Pi that may contain extensions, skills, prompts, and themes.

**Core**:
The predetermined set of independently installable Pi packages that defines LazyPi's baseline experience. _Avoid_: Profile, bundle

**Extra**:
An optional, named capability that may require one or more Pi packages or other Extras. _Avoid_: Profile

**Community package**:
A discoverable Pi package that LazyPi has not selected for its Core or Extras. _Avoid_: Curated package
